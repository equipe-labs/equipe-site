## 무엇을 배울지
- **오브젝트 하나 + 빛 하나**: 다크에선 검정 #000 위 검은 삼각형 뒤에서 흰 빛이 새어 나오는 역광(림 라이트). 라이트에선 같은 삼각형에 부드러운 그림자. 그림은 단 하나, 장식 0. 색 없이 빛의 방향만으로 깊이를 만든다.
- **3단 비대칭 히어로**: 왼쪽 제목 + 버튼 둘, 가운데 오브젝트, 오른쪽 작은 글자 세 줄(`For coding agents / To ship apps and agents / Automated by agents`). 가운데 정렬 템플릿과 달라 바로 "디자인된" 느낌.
- **조인 자간**: 64px/400인데 자간 −3.84px(−0.06em), 행간 1.0. 굵지 않고 촘촘한 큰 글자가 비싸 보이는 핵심.
- **폰에서 재배치**: 390에선 삼각형이 위로, 제목 가운데, 오른쪽 세 줄은 모노 한 줄(`For coding agents`)로 바뀌고 버튼은 전체 폭 알약 2개.
- 아래 섹션: 실제 고객 제품 화면(Notion AI 창, Zapier 사이트)을 옅게 잘라 보여주고, 옆에 "Notion powers millions…" 한 문장 + 기능 목록. 제품 증거 = 실물 화면.
- 고객 로고 줄이 히어로 바로 아래, 한 줄 6개, 넓은 간격.
