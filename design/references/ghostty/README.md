# Ghostty — 다크 위에 창 하나, 그 안의 조용한 애니메이션

- 링크: https://ghostty.org/ (2026-11-08 방문)
- 찾은 곳: 라이브 사이트 직접
- 방향: **3 (제품 오브젝트 히어로)**
- 스크린샷: `1440.jpg` (ASCII 애니메이션이 무거워 공유 브라우저 스크린샷이 자주 시간 초과 — 별도 컨텍스트로 촬영)

## 무엇을 배울지
페이지 첫 화면 = macOS 창 프레임 하나. 그 안에서 문자(ASCII)로 된 그림이 천천히 움직이고, 창 밑에 한 문장 + 버튼 두 개(Download / Documentation)뿐. 다크 #0F0F11 위에 얇은 테두리 창 하나가 "오브젝트"가 되는 가장 단순한 형태 — 우리 결정 카드 하나를 그 자리에 두는 3번 방향의 뼈대.

## 가져오지 않을 것
유령 마크/ASCII 유령 그림, 카피, 파란 ASCII 색. 애니메이션 비용(우리는 가볍게).

## 타입 / 색
- 본문 Pretendard Std Variable(한글 호환!) 14–16px, 코드 JetBrains Mono
- 배경 #0F0F11, 텍스트 흰색 / 보조 #828286, 버튼 테두리 하나만 파랑
