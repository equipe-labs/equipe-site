# Cursor (홈 / 기능) — 빛바랜 유화 한 장 위에 실제 제품 창을 얹은 히어로

- 링크: https://cursor.com/agents 는 로그인으로 넘어가고(307 → /api/auth/login), https://cursor.com/features 는 홈 https://cursor.com/en-US 로 넘어가서 홈을 찍음 (2026-11-08 방문). 비교용으로 https://cursor.com/product 도 확인
- 찾은 곳: 라이브 사이트 직접 (`equipe design shoot` + 그림이 늦게 뜨는 아래 섹션은 브라우저로 스크롤해서 확인)
- 방향: **1 (실제 제품 창이 히어로)** + 그림 배경
- 스크린샷: `1440.jpg`, `390.jpg` (쿠키 배너가 히어로 오른쪽을 덮은 채 찍힘), `art.jpg` (쿠키 거부 후 히어로 그림 + 창, 1440 폭)

## 무엇을 배울지
- **그림은 한 장, 그리고 죽여 놓은 색.** 히어로 그림은 19세기풍 풍경 유화(산·호수·하늘)인데 채도를 크게 빼서 회보라·회녹·바랜 분홍(#CEC9C1, #ABACB4, #897378)만 남았다. 페이지 배경 #F7F7F4 와 명도가 거의 같아서 그림이 "튀지" 않고 종이처럼 깔린다. 원색·네온·보라 그라데이션이 하나도 없다 — 이게 AI 일러스트처럼 안 보이는 첫째 이유.
- **붓 자국이 보이는 실제 재료감.** 확대하면 캔버스 결과 붓 터치가 그대로 남아 있다. 매끈한 렌더가 아니라 물감 질감이 있어서 생성 이미지 특유의 플라스틱 광택이 없다.
- **그림은 프레임, 주인공은 창.** 그림 블록은 1300×720 으로 좌우 70px 여백을 두고 모서리 거의 직각(rounded-xs). 화면 전체를 덮지 않는다. 제품 창(1080×620)이 그림 면적의 대부분을 가리고, 그림은 창 위·좌·우로 50~110px 정도만 테두리처럼 보인다. 그림의 구도(지평선·산)는 창 바깥 가장자리에서만 읽힌다.
- **창 그림자는 길고 옅게 + 1px 테두리.** `box-shadow: 0 28px 70px rgba(0,0,0,.14), 0 14px 32px rgba(0,0,0,.10), 0 0 0 1px rgba(잉크,.10)`, radius 10px. 창 크롬은 #F2F1ED 로 그림보다 살짝 밝아서 떠 보인다. 두 번째 창(CLI)을 오른쪽 아래로 겹쳐 깊이를 만든다.
- **글자는 그림 위에 절대 안 올린다.** 헤드라인·CTA 는 그림 블록 위쪽의 빈 크림 배경에 있다. 그림은 글자 대비를 신경 쓸 필요가 없는 자리에만 쓴다.
- **아래 섹션은 그림 → 그림에서 뽑은 단색으로 교대.** 홈의 기능 카드 4개 중 2개는 다른 유화(바다·들판), 2개는 그림의 평균색 같은 단색(#D9D5CF, #B6B9BE). /product 페이지는 아예 전부 단색 칸(#CFCEBC 등)이다. 그림을 아끼고, 같은 색 가족으로 리듬만 맞춘다.
- 폰(390)에서도 그림은 화면 폭에서 좌우 19px 여백을 두고 그대로, 창은 오른쪽이 잘려 나간다(축소하지 않고 크롭).

## 가져오지 않을 것
Cursor 로고·카피·CursorGothic, 그들이 쓰는 실제 유화 이미지들, 크림 배경 톤 그대로. "Mission Control" 같은 데모 콘텐츠.

## 타입 / 색
- CursorGothic (h1 26px/400, 행간 32.5px, 자간 -0.325px — 히어로 글자가 작고 조용함), 코드 Berkeley Mono
- 배경 #F7F7F4, 텍스트 #26251E, 보조 텍스트는 같은 잉크의 60% 정도 회색
- 그림 팔레트: #CEC9C1 / #ABACB4 / #897378 (바랜 회색 계열만)
- 포인트: 주황 텍스트 링크와 작은 주황 "Build" 배지뿐
