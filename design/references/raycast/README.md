# Raycast — 거의 검은 바탕에 빛이 든 빨간 유리 줄무늬, 그 아래 진짜 앱 창

- 링크: https://www.raycast.com/ (2026-11-08 방문, 라이브 사이트)
- 찾은 곳: 라이브 사이트 직접
- 방향: **3 (제품 오브젝트 히어로)** + **1 (아래 섹션의 실제 AI 창)**
- 스크린샷: `1440.jpg`, `390.jpg` — 데스크톱 히어로 그림은 WebGL `<canvas>`(1200×967)라 촬영 도구에서 빈 칸으로 나옴. 실제 화면엔 390처럼 빨간 유리 줄무늬가 제목 뒤에 깔린다.

## 무엇을 배울지
- **빛이 있는 그림 한 장이 브랜드**: 히어로는 사선으로 기울어진 빨간 반투명 줄무늬(입자감 있는 노이즈 + 가장자리 블러). 그라데이션 오브가 아니라 "물건에 빛이 닿은" 느낌이라 비싸 보인다. 색은 빨강 하나뿐이고 나머지는 #07080A 검정.
- **버튼이 물리 키캡**: "Download for Mac" 은 연회색 #E6E6E6 바탕에 그림자 4겹(바깥 2px 어두운 링 + 흰 14px 글로우 + 위쪽 inset 하이라이트 + 아래 inset 그림자). 평평한 버튼 하나와 이 버튼 하나의 차이가 "만든 티"다.
- **작은 모노 메타 줄**: 버튼 아래 `macOS Tahoe and Apple Silicon required` / `Install via Homebrew | Download V1` 를 GeistMono 회색으로. 진짜 제품이라는 신호.
- **넓은 여백, 큰 제목 하나**: 첫 화면엔 제목 64px/600, 설명 두 줄, 버튼 하나. 나머지는 스크롤.
- **아래 섹션은 진짜 앱 창**: "AI AGENT" 빨간 모노 아이브로우 → 실제 Raycast AI 창(사이드바 대화 목록, `Fetching assigned tasks / Fetching issue details` 단계 로그). equipe의 "에이전트가 일하는 로그"를 보여주는 방식과 같다.
- **카드에 색 조명**: 확장 카드(Linear·Google Translate·Spotify)마다 해당 브랜드 색이 카드 아래에서 은은히 번진다 — 검정 위에서 카드가 떠 보이는 이유.
- 스크롤하며 섹션이 서서히 나타남(촬영본에서 반쯤 투명한 키보드 그리드가 그 흔적).

## 가져오지 않을 것
Raycast 로고·카피("Your shortcut to everything"), 빨간 줄무늬 그림 그 자체, 키보드 일러스트, 확장 카드의 타사 브랜드 색.

- 포인트 하나: 빨강 (`--color-red` #FF6161, 그림 속 #D6394C 근처)
