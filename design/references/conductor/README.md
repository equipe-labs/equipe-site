## 무엇을 배울지
- **equipe와 가장 가까운 제품**: "Run a team of coding agents" — 히어로 창이 왼쪽 워크스페이스 목록(`Revamp Cloud Conductor d… 7d`, `Landing page copy 10h`), 가운데 대화(`5 tool calls`, `17 tool calls, 3 messages`, "Done and pushed."), 오른쪽 `#8376 · Ready to merge · Merge` + 변경 파일 74개(+53 −46). "에이전트가 하고, 사람은 머지만" 을 설명 없이 창 하나로 보여준다.
- **배경이 텍스처로 된 그림**: 라이트에선 #2F92ED→#4CBDF9 하늘에 문자/점으로 찍은 구름, 다크에선 검정 #000 위에 같은 점 무늬가 별밤처럼. 그라데이션 블롭이 아니라 "문자로 만든 그림"이라 개발자 도구답고 수작업 느낌.
- **글자 스크램블**: 제목 마지막 단어가 무작위 글자에서 제자리로 풀리는 애니메이션(촬영본의 "on tomc loas" 가 그 중간 프레임). 픽셀 워드마크와 같은 언어.
- **히어로 글자가 작다**: 36px/600. 창이 주인공이고 문장은 거든다. 인용 한 줄 + 실제 사람 이름/회사(사회적 증거)를 제목 바로 아래 둠.
- 창은 실제 macOS 크기 비율, 얇은 테두리 + 큰 부드러운 그림자로 하늘 위에 떠 있음. 폰에선 같은 창을 축소해 통째로 보여줌.
- 아래 섹션은 흰 바탕 + 얇은 테두리 상자 + 회색 설명만 — 장식 없음.
