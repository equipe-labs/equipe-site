## 무엇을 배울지
- **그림(painting)은 없다. 대신 손그림 선.** 섹션마다 위에 작은 잉크 스폿 일러스트 하나(새싹, 공구함, `</>` 창, 물음표, 그물). 떨리는 펜 선 + 회색 한 톤 채움. 크기 ~80px. 사람이 그린 흔적이 확실해서 AI 일러스트로 안 읽힌다. 장식이 아니라 섹션 표지 역할.
- **히어로는 그림 없이 제품 창만.** 크림 배경에 h1 왼쪽, 실제 Claude Desktop 창 오른쪽. 창은 아주 옅은 그림자 + 1px 선, 둥근 모서리. 히어로는 그림보다 "실제 작업 내용"(결제 중복 버그 디버깅)으로 신뢰를 산다.
- **색 판 위에 제품을 잘라 붙인다.** 기능 카드 3장: 흙 주황 #D77656, 오트 #E4DCCF, 하늘 #6C9CCA 단색 판(radius 24px)에 아주 옅은 손그림 곡선 무늬가 깔려 있다. 그 위에 터미널/에디터/웹 화면을 판 밖으로 잘려 나가게(오른쪽·아래로 블리드) 얹는다. 그림자 거의 없음 — 평면 콜라주.
- **색은 셋, 전부 흙빛.** 원색 대신 점토·귀리·바랜 하늘. 판끼리 명도가 비슷해서 나란히 놔도 시끄럽지 않다.
- **글자는 색 판 위에 올리지 않는다.** 카드 제목·설명은 판 아래 크림 배경에.
- 폰(390)에서도 h1 세리프 크게(가운데 정렬), 그 아래 다운로드 버튼. 일러스트는 같은 크기 유지.

## 가져오지 않을 것
Anthropic/Claude 로고·별 마크, anthropicSerif/Sans, 그들의 손그림 아이콘 세트 자체, 클레이 주황 #D77656 그대로(그들 브랜드 색), 카피.
