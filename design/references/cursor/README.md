## 무엇을 배울지
"Cursor Desktop" 창 왼쪽 열이 `IN PROGRESS 1 / READY FOR REVIEW 4` 로 상태별로 묶인 작업 목록 — 진행 중 하나는 스피너, 나머지는 체크 + `now / 10m / 30m` 시간. equipe의 "일하는 중 / 승인 대기" 보드를 히어로로 보여주는 구조와 거의 같다. 데스크톱 CTA는 "Download for macOS ↓" 한 개로 분명하고, iPhone에선 다운로드 대신 "시작하기"로 바꾼다.

## 가져오지 않을 것
Cursor 로고·카피, 유화 배경 이미지, 크림 배경 톤. 폰에서 "시작하기→로그인"으로 보내는 처리(우리 폰 방문자에겐 맞지 않음).
