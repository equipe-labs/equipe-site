## 무엇을 배울지
- **세리프 128px 한 방**: "Practices for building" 을 Tiempos Headline 128px/400, 행간 1.0. 다크 SaaS 사이트 대부분이 산세리프인 가운데 세리프 하나로 "에디토리얼/철학"의 무게가 생긴다. 위엔 14px 대문자 회색 아이브로우, 아래 17px 회색 설명 3줄 — 크기 대비가 극단적.
- **선 그림이 이미지**: 이미지 대신 SVG 선(약 500개 path/circle) — 점선 원 두 개가 겹치고, 겹친 부분만 가는 사선 해칭, 원 둘레에 흰 실선 호 하나가 빛처럼 지나감. 사진·3D 없이도 "정밀 도면" 같은 디테일.
- **번호 목차**: `INTRODUCTION / DIRECTION / BUILDING` 섹션 + 오른쪽 정렬 Berkeley Mono `1.1 / 2.1 … 3.6`. 숫자 하나로 체계·질서가 보인다. equipe의 단계/로그 표기에 그대로 응용 가능.
- **색은 거의 없음**: 배경 #08090A, 제목 #F7F8F8, 나머지 전부 #8A8F98 회색. 강조는 흰 호 하나.
- 폰에선 제목이 왼쪽 정렬로 바뀌고 원 그림은 겹친 렌즈 부분을 크게 잘라 보여줌.
