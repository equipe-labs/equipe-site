- 링크: https://mercury.com/ (2026-11-08 방문, 라이브 사이트)
- 찾은 곳: 라이브 사이트 직접 (`equipe design shoot` 은 히어로 아래가 스크롤 애니메이션이라 비어 나옴 → 브라우저로 스크롤해서 확인)

- 스크린샷: `1440.jpg`, `390.jpg`, `art.jpg` (스크롤 800px 지점: 노트북 화면 안에 실제 Mercury 대시보드가 보이는 프레임)

## 무엇을 배울지
- **그림 안에 제품이 "물건"으로 들어 있다.** 풍경 한가운데 작은 책상+의자+노트북, 노트북 화면에 실제 대시보드. 스크롤하면 영상(hero-scrub)이 노트북으로 다가가 화면이 커지고, 다음 섹션에서 같은 다크 UI 카드("Accounts")로 이어진다. 그림과 제품이 같은 이야기 하나다 — 장식용 배경이 아니라.
- **피사체는 작게, 풍경은 넓게.** 첫 화면에서 책상은 화면 폭의 20% 남짓. 넓은 여백(안개 낀 계곡)이 조용함을 만든다.
- **가장자리는 흐리고 어둡게.** 화면 네 귀퉁이에 블러+비네팅을 걸어 중앙만 초점. 위쪽 하늘은 바랜 분홍·하늘색(#C4968F → 회청)이라 흰 글자가 그 위에 올라가도 읽힌다. 아래는 페이지 배경 #171721 로 녹아든다.
- **색 온도 하나.** 해질녘 한 순간의 색만 쓴다: 회청 그림자 + 분홍 하늘 + 이끼 녹색. 채도 낮음. 버튼 보라(#5266EB)만 유일하게 선명하다.
- **글자는 그림 하늘 위, 가운데 정렬, 작게.** h1 49px/480, 흰색이 아니라 살짝 푸른 #EDEDF3. 입력창·보조 버튼은 반투명 유리.
- **주의 — 이건 AI 합성처럼 보일 위험이 있는 쪽.** "산 위의 책상" 같은 초현실 사진 합성은 지금 생성 이미지의 흔한 클리셰다. Mercury 가 버티는 이유는 (1) 스크롤로 제품까지 이어지는 연출, (2) 사진 그레인과 실제 렌즈 같은 심도, (3) 아래부터는 사진을 다시 쓰지 않고 차분한 3D 오브젝트·실사 인물 사진으로 바꾸는 절제. 우리가 이 방향을 쓰면 "책상 하나" 같은 상징 오브젝트 하나 + 제품으로 이어지는 동작이 있어야 한다.
- 폰(390)에서는 같은 장면을 세로로 크롭(책상이 아래쪽 1/3), 위쪽 하늘에 글자와 CTA 를 쌓는다.
