# Arc — 지금은 그림 없는 서비스 종료 안내 페이지 (검정 배경 + 세리프 + 제품 창 하나)

- 링크: https://arc.net/ (2026-11-08 방문, 라이브 사이트. Arc 는 2026-12-22 종료 예정이라 홈이 작별 편지로 바뀜)
- 찾은 곳: 라이브 사이트 직접
- 방향: **참고 약함 — 그림을 쓰지 않음.** 예전 Arc 의 일러스트/그림 홈은 더 이상 없다
- 스크린샷: `1440.jpg`, `390.jpg`, `art.jpg` (그림이 없어 대신 "Moving to Dia is easy" — 흰 배경에 Dia 창이 화면 오른쪽 밖으로 잘려 나가는 섹션)

## 무엇을 배울지
- **이번 조사 목적(그림 + 제품)에는 해당 없음.** 페이지에 그림·사진이 하나도 없다. 아이콘 로고, 손글씨 서명("Josh"), 텍스트, 제품 창 하나뿐.
- 그래도 볼 것: 검정 #0B0B0B 위 큰 세리프(Exposure 76px/600, 자간 -2.4px) + 가벼운 산세리프 본문(ABC Oracle 350). 손글씨 서명 한 줄이 "사람이 썼다"는 느낌을 주는 가장 싼 장치다.
- 제품 창은 그림자 대신 흰 배경 위 옅은 그림자와 1px 테두리, 화면 오른쪽 끝으로 잘라서(블리드) 크기를 키워 보이게 한다. 왼쪽 설명 목록은 스크롤에 따라 하나만 진하고 나머지는 흐리다.

## 가져오지 않을 것
Arc/Dia 로고, 작별 편지 카피, 서명, Exposure·ABC Oracle 폰트.

## 타입 / 색
- 제목 Exposure VAR (h1 76px/600), 본문 ABC Oracle (21px/350)
- 배경 #0B0B0B (위) → #FFFFFF (아래 섹션), 텍스트 #FFFFFF / #1A1A1A
- 포인트: 로고의 빨강·파랑 외엔 없음, 버튼은 #2F2F2F 알약
