- 링크: https://factory.ai/ (2026-11-08 방문, 라이브 사이트. factory.com 으로 리다이렉트)
- 찾은 곳: 라이브 사이트 직접
- 방향: **3 (제품 오브젝트 히어로)** + **1 (폰에서 보이는 실제 세션 창)**
- 스크린샷: `1440.jpg`, `390.jpg` (다크 모드 없음 — 다크로 찍어도 같은 라이트 화면)

## 무엇을 배울지
- **타입이 브랜드**: "AI CODING AGENTS FOR THE ENTERPRISE" 를 Geist 60px/500 대문자, 자간 −0.04em, 행간 1.0으로 꽉 조였다. 바로 아래 부제는 Geist Mono 따뜻한 회색. 대문자+모노 버튼(`DOWNLOAD FOR MAC`, `BOOK DEMO`)까지 한 목소리라 "산업용 기계" 같은 정밀함.
- **히어로 오브젝트 = 가짜 macOS 데스크톱**: 실제 메뉴바(`Finder File Edit … Wi-Fi 100% Tue 3:42 PM`)가 달린 화면 전체 폭 프레임, 안에는 거친 그레인 + 격자 위 흑백 빛 번짐, 가운데 앱 아이콘 하나. 앱이 "열리기 직전"의 데스크톱이라 제품을 맥 앱으로 보이게 한다. 색 없이 흑백 빛만으로 깊이를 낸다.
- **폰에선 진짜 앱 창**: 390에선 같은 자리에 다크 세션 목록(`SESSIONS · acme-productions`, 빨간 진행 점, `now / 2m / 4m / 13m`) 스크린샷 — 작업 목록 + 시간이 equipe 보드와 같은 구조.
- **CLI 한 줄**: 버튼 아래 `> curl -fsSL https://app.factory.ai/cli | sh` 복사 상자. 개발자에게 "진짜다" 신호.
- 고객 로고 그리드는 크고 단색, 넓은 간격. 기능 섹션은 4열 작은 글자 + 큰 여백(촬영본에서 그림은 스크롤 애니메이션이라 비어 있음).
- 로딩 시 버튼/CLI 상자가 흐리게 시작해 페이드인(촬영본에서 흐린 상태로 잡힘).
