- 스크린샷: `1440.jpg`

## 무엇을 배울지
세로 선 하나 위에 상태 세 가지 — ✓ 완료(`· 3d ago`), ● 진행 중(`· Running now…` 흐린 회색), ○ 예정(`· Upcoming`). 각 줄은 굵은 한 줄 제목 + 흐린 한 줄 설명. "점 하나만 차 있음 = 지금 일하는 중"이라는 표현이 우리 "작은 불 하나" 무드와 정확히 맞다. 티켓 진행 로그(계획 → 구현 → 디자인 QA → 승인 대기)에 그대로 대응.

## 가져오지 않을 것
예시 텍스트(Repository connected 등), 21st.dev 사이트 크롬/파란 버튼. 흰 카드 배경은 우리 다크 토큰으로 바꿀 것. 코드 복사는 하지 않고 패턴만.
