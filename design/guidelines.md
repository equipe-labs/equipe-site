# equipe.im 디자인 가이드라인

정본은 squad의 브랜드 가이드라인 v1(T-144, 사람 확정 2026-10-16)이다. 여기엔 사이트에서 바로 필요한 요약만 둔다. 값은 [`tokens.md`](tokens.md)가 가리키는 `tokens.json`을 따른다.

## 요약

- **이름·로고**: 이름 `equipe`(문장 안에서는 항상 소문자, 점 없음)와 로고(`e.`)를 유지한다. 점은 로고 그림에만 쓴다.
- **색**: 색은 둘 — 브랜드 파랑 하나와 의미색. 나머지는 따뜻한 중립(bone·void). 라이트·다크가 같은 역할 이름을 쓰고 값만 다르다. 글자 대비 4.5:1, 그래픽(포커스 링·점·아이콘) 3:1 이상. 색만으로 상태를 전달하지 않는다. 다크 모드는 `prefers-color-scheme`을 따르고 `data-theme="light|dark"`로 덮을 수 있다.
- **서체**: 웹은 Inter(자체 호스팅), 한국어 Pretendard, 일·중 Noto Sans. 코드는 JetBrains Mono. 제목 700, 본문 400, 버튼 600.
- **목소리**: 짧게·능동·구체. 과장어·느낌표·이모지·ALL CAPS 장식 금지. 한국어는 해요체.
- **로고 사용**: 늘이거나 기울이지 않고, 그림자·그라데이션·다른 글꼴을 쓰지 않는다. 최소 크기 마크 16px.
- **화면 변경**: 디자이너의 디자인 QA를 거친다.
