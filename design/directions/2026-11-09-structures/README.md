# T-521 구조 탐색

`structures.html`은 색·서체·생성 이미지 없이 같은 실제 이야기를 20가지 정보 구조로 탐색한다. 목적은 완성된 방향을 고르는 것이 아니라, 이전 라운드처럼 같은 `제목 + CTA + 앱 창` 뼈대를 반복하지 않게 구조의 범위를 넓히는 것이다.

고정한 이야기:

1. LinkedIn 유입 18건, 다운로드 클릭 0건.
2. PM이 iPhone 인앱 브라우저에서 Mac 설치로 이어지는 길이 없다고 판단한다.
3. designer·frontend·QA가 새 폰 동선을 설계·구현·검증한다.
4. founder에게 공개 결정이 온다.
5. 공개 뒤 다시 측정한다. 개선 수치는 아직 없으므로 쓰지 않는다.

모든 숫자와 흐름은 `2026-11-07-site-rebrand.md`와 현재 equipe 기능에 근거한다.
